# Gestion des prestations DJ et animation evenementielle

Projet TFE - Application Ultimate DJ.

## Objectif du projet

Ce projet vise a concevoir puis developper une application web permettant de gerer des prestations DJ et d'animation evenementielle.

L'application devra notamment permettre :

- la consultation des offres commerciales et des options payantes ;
- le choix d'un DJ selon ses disponibilites ;
- la creation d'une demande de devis ;
- la gestion des rendez-vous preparatoires pour les gros evenements ;
- la generation d'un contrat personnalise ;
- le paiement d'un acompte via un systeme de paiement (Stripe) ;
- le suivi de l'evenement ;
- la gestion des playlists, avis clients, langues et materiel.

## Documents presents dans ce depot

Les livrables actuels sont ranges dans `documents/rapport-et-livrables` :

- diagrammes dynamiques ;
- dictionnaire de donnees ;
- prototype navigable PowerPoint ;
- rapport ecrit version 1 ;
- schema et relations de base de donnees ;
- rapport de conception graphique.

## Etat du projet

Le depot contient pour le moment les documents de conception et les livrables deja produits. Le code de l'application sera ajoute dans les prochaines etapes.
